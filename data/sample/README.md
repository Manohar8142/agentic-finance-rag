# Sample dataset: SYNTHETIC

Everything in this folder is **synthetic data about a fictional company, "Northwind Analytics Ltd."**, written for demonstrating the RAG pipeline. It is not real financial information, does not describe any real company, and must not be used for any investment or business decision.

- `annual_report_fy2025.md`: excerpt-style annual report narrative
- `q2_fy2026_earnings_call.md`: mock earnings-call transcript
- `risk_factors.md`: risk disclosures
- `financials.csv`: six quarters of figures in USD millions (Q1 FY2025 to Q2 FY2026)
